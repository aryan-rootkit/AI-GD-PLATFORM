# AI Group Discussion Platform

Monorepo layout: `client/` (frontend), `server/` (backend), `docs/` (product and system design).

## Quick start

1. Copy `.env` and fill in secrets and service URLs for your environment.
2. Optional: `docker compose up -d` for PostgreSQL and Redis.
3. Initialize and run `client` and `server` once their stacks are chosen (see each `package.json`).
